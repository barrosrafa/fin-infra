# AWS reference only

These modules are an architectural reference. They are not the source of truth for the declared Vercel/Render/Neon/Redis/Aiven runtime. The workflow only validates configuration; it does not plan or apply a deployment and requests no AWS credentials.

Before activation, replace all placeholder secrets, images, account IDs and backend settings, create an explicit migration plan and verify costs, IAM and rollback. See `fin-docs/RUNTIME_ARCHITECTURE.md` and `PLANO_MELHORIA_EXECUTAVEL_2026-10-30.md`.
